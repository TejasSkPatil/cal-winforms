# 🧮 Calculator WinForms (.NET)

A simple and modern **Calculator Application** built using **C# and Windows Forms (.NET)**.  
This project demonstrates basic arithmetic operations with a clean UI.

---

## 🚀 Features

- ➕ Addition  
- ➖ Subtraction  
- ✖️ Multiplication  
- ➗ Division  
- 🔄 Clear (C)  
- ➕/➖ Toggle Sign  
- 📊 Percentage (%)  
- 🔢 Decimal Support  
- 🎨 Modern Dark UI Design  


## 🛠️ Technologies Used

- C#  
- .NET (WinForms)  
- Visual Studio Code / Visual Studio  


## 📂 Project Structure


CalculatorApp/
│
├── Form1.cs # Main calculator logic
├── Form1.Designer.cs # UI components
├── Program.cs # Entry point
├── CalculatorApp.csproj # Project configuration

### 1️⃣ Clone the repository

cd calculator-winforms
